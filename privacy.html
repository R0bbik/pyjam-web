Privacy Policy

How PyJam handles data obtained through Google, YouTube, Meta and TikTok APIs.

Who uses PyJam

PyJam is used only by the owner of the Draugskald project to manage the project's own accounts. It does not offer sign-in to the public and does not collect data about other people's accounts.

What data PyJam accesses

  • Google / YouTube (YouTube Data API, YouTube Analytics API): the Draugskald channel's videos, playlists, comments and statistics; uploading videos, thumbnails, playlist items and comments on that channel.
  • Meta (Facebook Pages API, Instagram Graph API, Threads API): the Draugskald Page, Instagram and Threads accounts: publishing posts and Reels, comments, and insights of those accounts.
  • TikTok (Content Posting API): publishing videos to the Draugskald TikTok account and reading their status and statistics.

Public comments and aggregated statistics may contain data about viewers as provided by the platforms (for example public usernames in comments). PyJam does not request or store viewers' private data.

How the data is used

Only to publish Draugskald's own content and to show the project owner how that content performs. Data is not sold, shared with third parties, used for advertising or used to train AI models.

Storage and security

Access tokens and statistics are stored on the owner's private computers, in files and a database readable only by the owner, and are never published in source code. Data is kept while the project uses the respective platform and deleted when no longer needed.

Google API Services User Data Policy

PyJam's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. PyJam uses YouTube API Services; see also the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google security settings.
